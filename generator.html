Generator Halaman Lokasi

Alat resmi pembuat halaman lokasi JEJAKRUTE — sesuai template situs saat ini. Isi formulir, lihat pratinjau langsung, lalu unduh berkas HTML jadinya beserta JSON datanya. Cocok untuk menambah tempat baru atau memperbarui data tempat yang sudah ada.

Aturan data JEJAKRUTE: isi hanya fakta yang terverifikasi dari sumber. Bidang yang belum terverifikasi kosongkan saja — halaman akan menyembunyikannya dengan rapi. Status keamanan wajib menyebut tanggal sumbernya.

Pratinjau Langsung

Pratinjau memakai template & gaya persis halaman live. Seksi Rute Komunitas tampil kosong di berkas unduhan — di situs live ia terisi otomatis dari database komunitas berdasarkan ID lokasi. Spanduk khusus 5 gunung pilot diatur terpisah oleh pembangun situs.

Cara memakai hasil: serahkan berkas HTML (untuk ditempatkan di folder gunung/ atau lokasi/ situs) dan JSON data (untuk arsip riset & pembangun situs) kepada pengelola JEJAKRUTE. Alat ini berjalan sepenuhnya di browser — tidak ada data yang dikirim ke mana pun.
